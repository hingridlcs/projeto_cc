# Gino Petshop

Landing page estática para um petshop fictício, em português (pt-BR). Apresenta serviços, seção sobre, galeria, depoimentos e um formulário de contato.

## Tecnologias

- HTML5
- CSS3 (puro, sem framework — estilos em `<style>` no próprio `index.html`)

Não há JavaScript, build tooling, gerenciador de pacotes, dependências ou suíte de testes.

## Estrutura

```
index.html   # página única com todo o markup e estilos
```

## Como rodar

Basta abrir `index.html` diretamente no navegador. Não há processo de build, lint ou testes.

## Seções da página

- **Header** — logo e navegação por âncoras
- **Hero** — chamada principal com CTA de agendamento
- **Serviços** — banho & tosa, consulta veterinária, hospedagem, loja de produtos
- **Sobre** — texto institucional
- **Galeria** — grade de itens ilustrativos
- **Depoimentos** — avaliações de clientes
- **Contato** — informações de contato e formulário (sem back-end associado)
- **Footer** — links sociais e copyright
